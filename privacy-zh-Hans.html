隐私政策

生效日期：2026年10月6日

噪音分贝仪在您的设备上运行，无需注册账号。我们不进行广告追踪或第三方使用统计。

数据与权限

麦克风用于测量分贝和录制音频；相机仅用于您选择的录像功能；相册权限仅用于添加录制视频，不读取已有照片或视频。

录制内容、分贝读数、日期、时长、备注和设置保存在设备上，用于播放、历史记录、图表和报告。除非您主动向我们分享，否则我们不会收到这些内容。

分享与相关服务

文件仅分享至您选择的目标。购买由 Apple 处理，我们不会获得您的完整支付信息。根据您的设置，Apple 可能备份 App 数据或同步保存到相册的视频。相关服务适用各自的隐私政策。

本网站使用 GitHub Pages，GitHub 会出于安全目的记录访问者的 IP 地址。请参阅 GitHub 隐私声明。

客服沟通

您发送邮件后，我们会收到您的邮箱地址和内容。反馈草稿包含 App/iOS 版本、设备型号、会员状态、语言和地区，您可在发送前修改。我们仅将这些信息用于客服，并在处理请求所需或法律要求的期间保留。

您的选择与数据删除

已保存的记录会保留至您在 App 内删除记录或删除 App。导出文件和备份需要单独管理。您可在 iOS 设置中撤销麦克风、相机和相册权限，也可联系我们请求删除客服邮件，法律要求保留的记录除外。

联系与更新

咨询或删除请求：noise-recorder-pro@qq.com。本政策变更时，我们会更新生效日期。
