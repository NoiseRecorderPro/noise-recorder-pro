私隱政策

生效日期：2026年10月6日

噪音分貝儀在閣下的裝置上運行，無需註冊帳戶。我們不進行廣告追蹤或第三方使用統計。

數據與權限

麥克風用於測量分貝和錄製音訊；相機僅用於閣下選擇的錄影功能；相簿權限僅用於加入錄製影片，不讀取已有相片或影片。

錄製內容、分貝讀數、日期、時長、備註和設定儲存在裝置上，用於播放、歷史記錄、圖表和報告。除非閣下主動向我們分享，否則我們不會收到這些內容。

分享與相關服務

檔案僅分享至閣下選擇的目標。購買由 Apple 處理，我們不會獲得閣下的完整付款資料。根據閣下的設定，Apple 可能備份 App 數據或同步儲存到相簿的影片。相關服務適用各自的私隱政策。

本網站使用 GitHub Pages，GitHub 會出於安全目的記錄訪客的 IP 位址。請參閱 GitHub 私隱聲明。

客戶服務溝通

閣下傳送電郵後，我們會收到閣下的電郵地址和內容。意見回饋草稿包含 App/iOS 版本、裝置型號、會員狀態、語言和地區，閣下可在傳送前修改。我們僅將這些資料用於客戶服務，並在處理請求所需或法律要求的期間保留。

閣下的選擇與數據刪除

已儲存的記錄會保留至閣下在 App 內刪除記錄或刪除 App。匯出檔案和備份需要另行管理。閣下可在 iOS 設定中撤銷麥克風、相機和相簿權限，亦可聯絡我們要求刪除客戶服務電郵，法律要求保留的記錄除外。
